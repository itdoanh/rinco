## Per-page expectations
- Each page must show real data (no Lorem ipsum, no "Mock", no "Test", no "Placeholder")
- Counts in dashboards must show >0 (e.g., "1,234 leads", "5 tenants")
- Login uses seed creds (e.g., admin@apexfintech.vn / rinco_dev_password)

## Live verification template

```bash
# Landing
curl -s http://localhost:3000/apexfintech | grep -E '<form|<script.*pixel' | head -5

# Admin portal login
curl -s -X POST http://localhost:3001/api/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"email":"admin@apexfintech.vn","password":"rinco_dev_password"}'
# Use returned token in Authorization header for next requests
TOKEN=...
curl -s http://localhost:3001/dashboard -H "Authorization: Bearer $TOKEN"
curl -s http://localhost:3001/leads -H "Authorization: Bearer $TOKEN"
curl -s http://localhost:3001/billing -H "Authorization: Bearer $TOKEN"

# Tenant site
curl -s http://localhost:3002/apexfintech | grep -E 'hero|cta' | head -3

# Meeting UI
curl -s http://localhost:3003/room-abc | grep -E 'video|control' | head -3
```
